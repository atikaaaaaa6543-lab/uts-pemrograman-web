# UTS Pemrograman Web I

## Aplikasi Pemesanan Menu

Aplikasi web untuk menampilkan daftar menu, mencari menu, melakukan pemesanan, dan mengelola keranjang menggunakan PHP Session.

### Fitur
- Menampilkan daftar menu.
- Pencarian menu.
- Validasi input pemesanan.
- Keranjang belanja menggunakan session.
- Perhitungan subtotal, diskon, dan total pembayaran.
- Preferensi kategori menggunakan cookie.

### Teknologi
- PHP 8.x
- HTML
- CSS
- Session dan Cookie

### Cara Menjalankan
Jalankan aplikasi menggunakan server PHP lokal, kemudian buka file index.php melalui browser.

### Dokumentasi Pengujian
Bukti pengujian disimpan dalam folder dokumentasi/pengujian.
